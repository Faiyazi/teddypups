# TeddyPups React Website

A responsive React + Vite recreation inspired by the supplied TeddyPups reference site.

## Run locally
1. Install Node.js 18+ (or current LTS).
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL Vite prints (usually http://localhost:5173).

## Production build
`npm run build` creates the `dist/` folder. `npm run preview` previews the production build.

## Included
- Responsive home, puppies listing, puppy detail, promise/about, FAQs, and contact views
- Puppy search, breed filter, and availability filter
- WhatsApp enquiry links with prefilled messages
- Mobile navigation and floating WhatsApp action
- Sample puppy content to replace with real availability

## Before publishing
- Puppy listings and photos in this demo are sample content. Replace with current, verified puppy information and images.
- Confirm the business WhatsApp number and email before launch.
- Images load from Unsplash and fonts load from Google Fonts, so internet access is required for those assets.
- This is a front-end starter. The contact form prepares a WhatsApp message; it does not store leads. For an admin panel or live inventory, add a backend/CMS.
